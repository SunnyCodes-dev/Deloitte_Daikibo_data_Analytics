## Projects

### 1. Manufacturing Telemetry Analysis
**Analyzing 160,000+ IoT records to identify production bottlenecks**

- Analyzed telemetry data from 4 global manufacturing facilities
- Identified critical downtime patterns and machine failures
- Created interactive dashboards in Python and Tableau

**Key Findings:**
- Daikibo Factory Seiko experienced 480 minutes of downtime
- LaserWelder machines were 100% responsible for failures
- Provided actionable maintenance recommendations

**Technologies:** Python, Pandas, Matplotlib, NumPy, Tableau

[View Project Details →](./01-Telemetry-Analysis/)

### 2. Gender Pay Equality Analysis
**Classifying salary equality across organizational hierarchy**

- Analyzed 37 job roles across 4 factories
- Classified roles by gender pay equality severity
- Created comprehensive 6-panel analytical dashboard

**Key Findings:**
- 51% of roles show fair equality
- Senior management roles show highest inequality
- Identified priority areas for intervention

**Technologies:** Python, Pandas, Matplotlib, NumPy, Excel
